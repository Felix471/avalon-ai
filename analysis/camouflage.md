# Camouflage metrics (deterministic)

Generated by `analysis/camouflage.ts` from `data/games.jsonl` (140 games).

Quest round is derived from the array index (index + 1), not from the logged `quests[].round`,
which is unreliable in this dataset (see README "Known data issues").

Definitions: an "evil quest action" is a fail/success choice logged for a player with an
evil role who is on the executed quest team. Sabotage share = fail / evil actions in that
round. Early-camouflage rate = success / evil actions across rounds 1-2 (evil players
passing up an available sabotage while trust is being established).
